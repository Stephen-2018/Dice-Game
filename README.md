# 🎲 Simple Dice Game

A fun and interactive dice game built using **HTML**, **CSS**, and **JavaScript**. This project is a great starting point for beginners looking to understand how to combine front-end technologies to create a dynamic web game.

## 🚀 Features

- Roll two dice with a single click
- Display the result visually with dice images or numbers
- Declare the winner (2, 3 and 4 players) or a draw
- Simple, clean UI with responsive styling

## 🛠️ Tech Stack

- **HTML5** – Structure of the game
- **CSS3** – Styling and layout
- **JavaScript** – Game logic and interactivity

## 🎮 How to Play

1. Open `index.html` in your browser.
2. Click the "Roll Dice" button.
3. Two dice will be rolled.
4. The player with the higher number wins!
5. In case of a tie, it shows a draw.

## 🔧 Setup & Usage

1. Clone or download this repository.
2. Make sure all files (`index.html`, `style.css`, `script.js`, and `images/`) are in the same directory.
3. Open `index.html` in any modern web browser.
4. Play the game!
